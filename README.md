# LipatoS - Запрет изменения вдохновения

Модуль для **Foundry Virtual Tabletop** и системы **D&D 5e**, который запрещает обычным игрокам вручную включать и отключать вдохновение персонажа.

Внешний вид кнопки вдохновения не меняется. Управлять вдохновением могут только **ГМ и Assistant GM**.

## Версия

**1.0.1**

## Совместимость

- Foundry VTT: **14**
- D&D 5e: **6.0.0 и выше**

## Возможности

- запрещает игрокам вручную включать вдохновение;
- запрещает игрокам вручную отключать вдохновение;
- блокирует изменение не только через интерфейс, но и через альтернативные способы обновления Actor;
- не меняет внешний вид стандартной кнопки вдохновения;
- ГМ и Assistant GM работают без ограничений.

## Установка

В Foundry VTT откройте **Add-on Modules → Install Module** и вставьте ссылку на манифест:

`https://raw.githubusercontent.com/Lipatosha/LipatoS-inspiration-lock/main/module.json`
